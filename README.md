# Purchasing Desk downloads

Version 1.1.0 — native Android purchasing and maintenance ticket app.

- [Download Android APK](https://github.com/BaronYaakov/TicketApp/raw/refs/heads/downloads/PurchasingDesk-1.1.0-debug.apk)
- [Download complete Android Studio project](https://github.com/BaronYaakov/TicketApp/raw/refs/heads/downloads/TicketApp-1.1.0-source.zip)
- [Checksums](SHA256SUMS)
- [Source code and instructions](https://github.com/BaronYaakov/TicketApp/tree/main)

The APK supports Android 9 and newer. It is a debug-signed build with the same signing certificate as the previous APK, allowing an in-place update. Keep your app data by installing the update over the previous build.

The APK was built and validated with 17 passing unit tests, 17 passing Android tests, and zero lint issues. Foldable layouts were tested at compact and expanded emulator sizes; physical Fold7 acceptance testing remains.

This branch contains downloadable build files, separate from the application source on main.
